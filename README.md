# XAU-SMC Alert Bot (کاملاً رایگان، بدون نیاز به TradingView پولی)

این ربات خودش هر ۳۰ ثانیه قیمت طلا رو از یه API رایگان می‌گیره، خودش کندل ۵ دقیقه‌ای می‌سازه، و ساختار قیمت (BOS/CHoCH + Order Block + FVG + تأیید کندلی) رو تحلیل می‌کنه. وقتی یه ست‌آپ معتبر شکل بگیره، پیام رو به تلگرامت می‌فرسته. هیچ اشتراک پولی لازم نیست.

## بخش ۱ — آپلود کد تو گیت‌هاب

1. تو github.com یه ریپازیتوری جدید بساز (مثلاً `gold-alert-bot`)
2. فایل‌های `server.js` و `package.json` رو توش آپلود کن (فایل `xau_smc_alert.pine` رو هم می‌تونی نگه داری — فقط برای اینه که همون زون‌ها رو دستی هم رو چارت TradingView ببینی، اما دیگه لازم نیست ازش Alert بسازی)

## بخش ۲ — دیپلوی روی Render

1. render.com → **New** → **Web Service**
2. ریپازیتوری رو Connect کن
3. تنظیمات:
   - Build Command: `npm install`
   - Start Command: `npm start`
4. تو Environment Variables:
   - `TELEGRAM_TOKEN` = توکن بات از BotFather
   - `TELEGRAM_CHAT_ID` = آیدی عددی چتت (از userinfobot)
5. Create Web Service — یه آدرس می‌گیری شبیه `https://gold-alert-bot-xxxx.onrender.com`

## بخش ۳ — بیدار نگه‌داشتن سرور رایگان (مهم)

سرور رایگان Render بعد از ~۱۵ دقیقه بی‌فعالیتی خاموش می‌شه. برای این‌که ربات دائم قیمت رو رصد کنه:

1. برو **cron-job.org** یا **UptimeRobot.com** (هر دو رایگان)
2. یه Monitor/Cron Job بساز که هر ۱۰ دقیقه یه بار آدرس `https://gold-alert-bot-xxxx.onrender.com/` رو پینگ (GET) بزنه
3. همین کافیه — سرور همیشه بیدار می‌مونه و پولینگ قیمت (هر ۳۰ ثانیه) قطع نمی‌شه

## نکات مهم

- بعد از روشن شدن اولیه، ربات به حدود **۵۰-۶۰ دقیقه** زمان نیاز داره تا کندل‌های کافی جمع کنه و بتونه اولین سوئینگ ساختاری رو تشخیص بده — نگران نباش اگه اولش پیامی نیومد.
- می‌تونی وضعیت رو هر وقت خواستی از آدرس `.../status` چک کنی (نشون می‌ده چند کندل جمع شده).
- این سیگنال یه **تقریب خودکار** از منطق SMC هست، نه جایگزین تحلیل دستی من رو اسکرین‌شات. بعد از هر آلارم، بازم برام اسکرین‌شات بفرست تا تأیید نهایی بدم قبل از ورود واقعی.
- منبع قیمت (gold-api.com) رایگان و بدون کلید کار می‌کنه؛ اگه یه روز از دسترس خارج شد، بگو تا منبع رو عوض کنیم.
